# Build Stream -- Security

## API

API endpoints are secured with JWT-based authentication. TLS certificates for the API are stored under `<data_path>/build_stream/ssl/`; JWT keys are under `<data_path>/build_stream/build_stream_root/api/.auth/keys/`.

## Credentials

- Credentials (Build Stream, PostgreSQL, GitLab) are stored in `<input project dir>/build_stream_credentials.yml` with mode `0600`, Ansible Vault encrypted, with the vault key in `.build_stream_credentials_key` in the same directory.
- `cleanup` removes GitLab, Build Stream, PostgreSQL, the credential files, and vault keys; `-e cleanup_credentials=false` keeps the credentials.
- Tasks that handle credentials use `no_log`.

## Data path and playbook queue

The playbook queue under the Omnia data path drives root playbook execution on the OIM. The precheck warns when the data path is on an NFS mount. If NFS is used, export it with `root_squash` (the default), restrict the allowed clients, and run `exportfs -ra`. Do not place `OMNIA_SRC_PATH` inside the Omnia data path, because that path is mounted read-write into the Build Stream container.

## Cleanup

Build Stream cleanup removes project output, validation and watcher logs, playbook queues, API logs, TLS/runtime data, host playbook logs, and generated bytecode caches. PostgreSQL data is preserved by default.
