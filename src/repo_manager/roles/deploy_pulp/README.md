# deploy_pulp

## Description

Deploy and configure Pulp container for repository management

## Requirements

- Ansible >= 2.14
- Python >= 3.9

## Role Variables

See `defaults/main.yml` and `vars/main.yml` for available variables.

## Dependencies

None.

## Example Playbook

```yaml
- hosts: localhost
  roles:
    - role: deploy_pulp
```
