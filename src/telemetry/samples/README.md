# Telemetry Samples

Reference files for Telemetry deployment. These are **not** used at runtime — they
serve as documentation and starting-point examples.

## Files

| File | Description |
|------|-------------|
| `orchestrator_inventory.yaml` | Sample orchestrator inventory generated by orchestrator domain. Shows functional groups, kube_vip, and node attributes. |
| `csm_observability_values.yaml` | Sample Helm values file for karavi-observability chart. Configures PowerScale telemetry components (Karavi Metrics, OTEL Collector, Cert-Manager). |

## Usage

These files are reference documentation only. They are NOT copied to runtime by `domain-init.sh`.

For testing or reference, manually copy the files as needed:

```bash
# Copy sample files to telemetry directory for testing:
sudo mkdir -p /opt/omnia/telemetry
sudo cp samples/orchestrator_inventory.yaml /opt/omnia/telemetry/
sudo cp samples/csm_observability_values.yaml /opt/omnia/telemetry/
```

## Notes

- **orchestrator_inventory.yaml**: Generated dynamically by orchestrator's `generate_inventories` role during provisioning. Reference in `telemetry_config.yml` as `cluster_inventory`.
- **csm_observability_values.yml**: User-provided Helm values file - reference in `telemetry_config.yml` as `csm_observability_values_file_path`. Customize based on your PowerScale configuration.

## File Formats

### orchestrator_inventory.yaml
```yaml
all:
  children:
    kube_vip_group:
      hosts:
        kube-vip:
          ansible_host: 182.11.5.101
          ansible_user: root
    service_kube_control_plane_first_x86_64:
      hosts:
        kcp-node:
          ansible_host: 172.10.0.15
          service_tag: control
          group_name: grp1
    slurm_control_node:
      hosts:
        slurm-cp:
          ansible_host: 182.11.5.114
          service_tag: slurm_control
          group_name: grp3
```

**Structure:**
- `kube_vip_group`: Contains kube-vip host with ansible_host and ansible_user
- Functional groups: Service groups (service_kube_*, slurm_*) with node attributes
- Node attributes: `ansible_host`, `service_tag`, `group_name`

### csm_observability_values.yml
```yaml
karaviMetricsPowerscale:
  enabled: true
  image: quay.io/dell/container-storage-modules/csm-metrics-powerscale:v1.12.0
  collectorAddr: otel-collector:55680
  provisionerNames: csi-isilon.dellemc.com
  capacityMetricsEnabled: "true"
  performanceMetricsEnabled: "true"
  topologyMetricsEnabled: "true"
  authorization:
    enabled: false
    sidecarProxy:
      image: quay.io/dell/container-storage-modules/csm-authorization-sidecar:v2.5.0
    proxyHost:
    skipCertificateValidation: true

otelCollector:
  image: ghcr.io/open-telemetry/opentelemetry-collector-releases/opentelemetry-collector:0.150.1
  service:
    type: ClusterIP

cert-manager:
  enabled: true
```

**Key Sections:**
- `karaviMetricsPowerscale`: PowerScale metrics configuration (enabled for PowerScale telemetry)
- `karaviMetricsPowerflex/Powerstore/Powermax`: Other storage types (disabled for PowerScale deployment)
- `otelCollector`: OpenTelemetry Collector configuration
- `cert-manager`: TLS certificate management
